# 🧾 Mini Carnet de Contacts - Fullstack App

Ce projet est une petite application web pour gérer des contacts (nom, email, téléphone). Elle permet d'afficher une liste de contacts à partir d'une API Python (Flask) dans une interface React.

## 🧱 Structure

- `frontend/` : Application React (interface utilisateur)
- `backend/` : API Flask (Python) qui retourne une liste de contacts
- `requirements.txt` : dépendances Python

## 🚀 Lancer le projet

### 1. Backend (Flask)

```bash
cd backend
pip install -r requirements.txt
python app.py
```
